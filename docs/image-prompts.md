# Image prompts

One prompt per image, written to match the existing catalogue photography:
photoreal product mockups isolated on pure white, carrying artwork for invented
Southeast Texas businesses with the phone number (409) 225-2012 and www.pixelnpanel.com.

Each prompt is self-contained — copy one block, paste it into ChatGPT, save the result
to the path directly above it.

## Before you start

- **Ask for a square image.** Every existing catalogue image is 1000 x 1000.
- **Convert to `.webp`** before saving. ChatGPT returns PNG; the paths below all end `.webp`.
- **Check the small print.** Image models frequently garble phone numbers and URLs.
  Zoom in and confirm it reads exactly (409) 225-2012 and www.pixelnpanel.com, and regenerate if not.
- **The business names are fictional on purpose** and follow the ones already in your
  photos (Smokehouse 409, Grace Community Church, El Sol Taqueria). Do not swap in a real
  local business name — that would put another company's branding on your marketing.
